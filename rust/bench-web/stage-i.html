Evolution Wars — Stage I: Prepared Kinetics Session (браузерный benchmark)

Автоматический браузерный прогон Stage I. Измерения выполняет модульный Worker (stage-i-worker.js): инициализация WASM, подготовка сессии, холодный и тёплые тики preparedTS vs Rust/WASM-сессии, перенос данных (clone vs transfer), память параметров. Главный поток держит heartbeat-зонд (интервал 5 мс): по максимальным промежуткам видно, что расчёты в Worker не блокируют UI; для контраста после Worker на главном потоке выполняется блокирующий тик preparedTS. Требуется собранный pkg-web и сервер корня репозитория. Результат помещается в window.__stageIResult (JSON), ошибки — в window.__stageIError. Запуск в CI: npm run benchmark:browser (Chromium headless, Stage I browser benchmark).
