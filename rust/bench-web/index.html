Evolution Wars — Rust/WASM pilot: ручной браузерный benchmark

Страница Stage H для ручной проверки браузерной WASM-цели. Основной сравнительный benchmark (TypeScript против Rust/WASM и native Rust) выполняется командой npm run benchmark:rust; здесь измеряется только производительность WASM-ядра в браузере и время инициализации. Требуется собранный pkg-web (npm run wasm:build) и статический сервер корня репозитория (например npx serve .), т.к. WASM не загружается с file://.
