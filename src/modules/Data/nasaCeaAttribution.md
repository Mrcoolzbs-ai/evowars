## Что импортировано

Первая партия: **20 газовых веществ** (`phase: gas`) в слое `src/modules/Data/thermodynamicCatalog.ts`. Для каждого вещества из записи базы импортированы (и ничего сверх этого):

- ΔfH°(298.15 K), Дж/моль — числовое поле записи (known, origin `reference_range`);
- опубликованные коэффициенты NASA-7 Cp°(T)/R по сегментам — дословно (derivation.kind `published`, origin `numerical_approximation`, метод — аппроксимация NASA Glenn по CAP);
- диапазоны температур сегментов записи (нижние границы 200/300 K — как в записи, обновление Snyder 09.09.2021);
- reference state: газ, 298.15 K; давление стандартного состояния записью не задаётся и не назначается (1 atm ≠ 1 bar).

## Что не импортируется

- **S°(298.15 K) и ΔfG°(298.15 K)**: в записи базы отсутствуют; вычислитель термодинамических функций из коэффициентов NASA-7 в этом подэтапе не реализуется — значения `unknown` с пояснением (не нули, не подстановка).
- **Исходная табличная Cp(T)**: в thermo.inp публикуется только параметризация; Appendix B NASA TP-2002-211556 недоступен для верифицированного импорта — `tabulated` не заполняется.
- **Давление стандартного состояния**: записью не задаётся.
- **NIST SRD 69**: только внешняя качественная сверка порядков величин; числа NIST в проект не копируются.
- **ATcT**: не импортируется.
