# CHEMISTRY_ARCHITECTURE — Физическая химия и геохимия

> Stage 4.0, проект. Текущее состояние (стехиометрический движок,
> скрининг фаз) сохраняется как уровень 0; всё ниже — целевые уровни.

## 1. Принципы

1. Равновесие, кинетика и стехиометрия — ТРИ РАЗНЫЕ подсистемы, которые не
   подменяют друг друга (требование ТЗ §8.4).
2. Любая константа — с источником, диапазоном применимости и
   неопределённостью; иначе `unknown` и «не рассчитано».
3. Элементный баланс и заряд — инварианты каждого шага (уже реализовано
   для реакций; распространяется на решатели).
4. Неизвестное значение не подменяется нулём; идеальные модели (идеальный
   газ, закон Рауля) применяются только внутри заявленных условий.

## 2. Каталог веществ (целевая схема)

Расширение текущего `gases.ts` (12 веществ, молярная масса + качественные
описания) до `species/`-каталога:

| Поле | Тип | Источник-пример | Статус |
|---|---|---|---|
| id, формула, элементный состав | строка/record | IUPAC | есть (elementCompositions) |
| молярная масса | PhysValue | NIST/CODATA атомные массы | есть |
| заряд | int | — | новое (ионы) |
| класс вида | молекула/ион/радикал/минерал/аэрозоль | — | новое |
| фазовые переходы (T, P, ΔH) | PhysValue[] | NIST WebBook / ATcT | частично (CH₄, C₂H₆) |
| теплоёмкость Cp(T) | полином NASA-7 | NIST/ATcT/JANAF | целевое (4.3) |

только реально доступные данные (запрещено «все поля заполнены» ради
красоты). Хранение Cp/ΔH — в форме полиномов NASA-7 (совместимо с Cantera-
подходом и упрощает валидацию против первоисточников).

## 3. Химическая термодинамика

### 3.1 Что строится

- Термодинамика реакции: ΔrH, ΔrS, ΔrG из данных видов; K(T) = exp(−ΔrG°/RT).
- Химические потенциалы: μ_i = μ_i° + RT ln a_i (газ: a → f/p°, фугитивность).
- Активности/фугитивности — иерархия моделей:
  1. идеальный газ / идеальный раствор (условия: низкие p, далёкие от
     критических, разбавленность — проверяются явно);
  2. кубические EOS (Peng–Robinson, SRK) для неидеального газа;
  3. модели коэффициентов активности растворов (Davies/Debye–Hückel для
     воды; Pitzer — позже; неводные растворители — отдельние модели с данными).
- Равновесия: газовая смесь, жидкая смесь, газ–жидкость (растворимость
  Генри с константами из источников), кислотно-основное (водная химия),
  окислительно-восстановительное (pe/pH), минералообразование.

### 3.2 Ограничения честности

- Идеальные модели применяются ТОЛЬКО при выполнении условий; иначе
  результат помечается приближением или не вычисляется.
- PHREEQC — ориентир АРХИТЕКТУРЫ (спецификация, кинетика минералов,
  ионный обмен), не универсальный решатель для всех сред: он построен
  вокруг водной химии; для неводных/сверхкритических сред — свои модели.

## 4. Химическая кинетика (независимый движок)

### 4.1 Модель

- Элементарные реакции с законами скорости (r = k Π c_i^ν);
- k(T) — Аррениус k = A·(T/300)^n·exp(−E_a/RT) (модифицированная форма
  JPL) или тройная troe-форма для давления-зависимых;
- обратные реакции — либо прямо из данных, либо термодинамически
  согласованные через K(T) (только при наличии ΔG данных);
- механизмы: радикальные цепи, фотохимия (J-потоки из спектра × сечения),
  поверхностные реакции и граница раздела фаз — по мере данных.

### 4.2 Политика данных

- Источники: **JPL Chemical Kinetics and Photochemical Data for Use in
  Atmospheric Studies (Evaluation)** — приоритетный (проект страницы
  data-evaluation подтверждён; точный номер выпуска проверять вручную,
  страница загрузки блокирует автоматический доступ); KIDA — для
  низкотемпературной астрохимии с проверкой среды применимости
  (KIDA не является источником для водной химии).
- Каждая константа: A/n/E_a, T-диапазон, неопределённость (JPL указывает
  фактор), ссылка. Вне диапазона — экстраполяция запрещена без пометки.
- Данных нет → скорость `unknown` → реакция в механизме помечается
  «не рассчитано» (расширение текущего поведения `runKineticStep`).
- Произвольные коэффициенты вместо эксперимента — запрещено
  (`gameSpeedCoefficient` остаётся ТОЛЬКО в стехиометрическом
  игровом режиме, чётко отгороженном от кинетики).

## 5. Численные методы химии

### 5.1 Равновесие

- Задача: минимизация полной энергии Гиббса при ограничениях (элементы,
  заряд) — метод множителей Лагранжа (element potential / RAND-алгоритм),
  нелинейный решатель (Ньютон с линейным поиском).
- Контроль: сходимость по ΔG < tol, сохранение элементов/заряда до
  машинной точности, неотрицательность концентраций (лог-переменные).

### 5.2 Кинетика (ODE)

- Жёсткие системы: неявные методы (BDF/Radau) — интерфейс
  `SolverBackend`; в TS реализуем упрощённый BDF с диагональным якобианом
  для малых сетей; большие — через WASM/внешний движок (ADR-P7).
- Адаптивный шаг с контролем локальной ошибки; события (исчерпание
  реагента, достижение равновесия) — через detection + restart.
- Инварианты на каждом шаге: элементы, заряд, неотрицательность
  (клип с журналированием — не молча), энергетика (ΔH учёт при
  неизотермическом扩展).

### 5.3 Расщепление равновесия и кинетики

Равновесный расчёт и кинетическое продвижение — разные операции
(split operator: быстрый равновесный блок + медленный кинетический блок);
они никогда не вызывают друг друга неявно. Расписание — SIMULATION_ENGINE.

## 6. Многокомпонентные фазы и резервуары

- Фазы: газ, жидкая смесь, твёрдый раствор, минералы (стехиометрические
  конденсированные), растворённые газы, сверхкритический флюид (по
  критическим параметрам), аэрозоли; плазма — только при физическом
  обосновании (например, ионосфера) и данных.
- Несколько сосуществующих фаз: расчёт через общее равенство химических
  потенциалов (flash-расчёт) — целевой уровень после равновесного
  решателя; первый уровень — скрининг (сохраняется, честно помечен).
- Переходы: материальный баланс (уже есть в `transferSubstance`) +
  латентная теплота в тепловой контур (энергетическая связь — этап 4.8+).
- Один компонент может быть в нескольких резервуарах — текущий
  `SubstanceReservoirs` это уже поддерживает (контроль: суммы).

## 7. Геохимические циклы

- Каркас: направленные потоки между резервуарами (атмосфера, гидросфера,
  поверхность, кора, мантия, ядро, лёд, минералы, подповерхностные
  жидкости) в единых единицах **моль/м²/год** (или кг/м²/год с явным
  выбором), каждый поток = `ChemicalProcess` (реестр уже существует) +
  фактический rate, источник, неопределённость.
- Законы сохранения: элементный бюджет мира считается явным ledger'ом;
  сумма изменений за шаг = 0 (с точностью roundoff) — тест-инвариант.
- Процессы по мере данных: вулканическая дегазация, выветривание
  (параметрические законы с литературными константами), растворение/
  осаждение (через §3), поглощение океаном, окисление, атмосферная утечка,
  органический углерод (уровень «реестр без потока» до появления данных).
- Циклы: C, O, H, N, S, P, Si, металлы — реализуются как НАБОРЮЩИЕСЯ
  представления одного каркаса (не отдельные модули), начиная с C и O
  (кислородный баланс уже есть как частный случай — обобщается).

## 8. Критерии готовности

- **4.3 (каталог)**: ≥ 20 видов с термодинамикой (Cp-полином, ΔfH, S, G)
  и provenance; тесты полиномов против табличных значений при 298/1000/3000 K.
- **4.4 (равновесие)**: решатель воспроизводит K известных равновесий
  (например, диссоциация NH₃/N₂-H₂ при высоких T по табличным данным,
  CO₂+H₂ ↔ CO+H₂O) с относительной ошибкой < 1%; сохранение элементов 1e-12.
- **4.5 (кинетика)**: сеть из JPL-данных; интегратор на тестовой жёсткой
  задаче (Robertson) с сохранением неотрицательности; трекинг неопределённости факторов JPL.
- **4.9 (циклы)**: закрытый цикл C на тестовом сценарии сохраняет углерод
  в пределах 1e-9 за 1000 шагов; каждый поток имеет источник или `unknown`.
