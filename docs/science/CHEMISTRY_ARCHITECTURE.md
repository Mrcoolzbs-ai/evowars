## 1. Принципы

1. Равновесие, кинетика и стехиометрия — ТРИ РАЗНЫЕ подсистемы, которые не
   подменяют друг друга (требование ТЗ §8.4).
2. Любая константа — с источником, диапазоном применимости и
   неопределённостью; иначе `unknown` и «не рассчитано».
3. Элементный баланс и заряд — инварианты каждого шага (уже реализовано
   для реакций; распространяется на решатели).
4. Неизвестное значение не подменяется нулём; идеальные модели (идеальный
   газ, закон Рауля) применяются только внутри заявленных условий.

(если указано источником), фаза, стандартное состояние, условия и
конвенция — 1 bar / 298.15 K автоматически не назначаются, газовые /
жидкие / твёрдые / aqueous состояния одного вещества не смешиваются.

типизированный origin (8 значений); для known/estimated provenance
обязателен, для unknown числовое значение не создаётся. Валидация —
`validateThermodynamicProperties`. НЕ реализованы (не входят в 4.3.1):
вычислитель NASA-7, процедура подбора коэффициентов, массовый импорт
значений (≥20 видов — подэтап 4.3.2: NIST WebBook SRD 69 — основной
источник, ATcT TN 1.228 — для сверки ΔfH°, лицензия unverified — в
дистрибутив не включать до проверки).

**Про NASA-7 (ревизии 4.0.1/4.0.2)**: NASA-7 — это ПАРАМЕТРИЗАЦИЯ
термодинамических функций, а НЕ исходный универсальный формат всех записей
NIST или ATcT. Полином — производный артефакт, не замена первоисточника;
исходные термодинамические данные сохраняются отдельно.

**Математическая форма NASA-7 (ревизия 4.0.2; форма подтверждена
документацией Cantera, species-thermo)**. В каждом температурном диапазоне
семь коэффициентов a0…a6 задают:

    Cp°(T)/R = a0 + a1·T + a2·T² + a3·T³ + a4·T⁴

    H°(T)/(R·T) = a0 + a1·T/2 + a2·T²/3 + a3·T³/4 + a4·T⁴/5 + a5/T

    S°(T)/R = a0·ln T + a1·T + a2·T²/2 + a3·T³/3 + a4·T⁴/4 + a6

Теплоёмкость задаётся полиномом ЧЕТВЁРТОЙ степени по T; выражения
энтальпии и энтропии получаются ИНТЕГРИРОВАНИЕМ (H° — из Cp, S° — из
Cp/T) и содержат дополнительные члены: обратную температуру a5/T (в H°),
логарифм a0·ln T и константу a6 (в S°). Аппроксимация имеет ОГРАНИЧЕННЫЙ
температурный диапазон (классически — два диапазона со стыком); вне
диапазонов не применяется и не экстраполируется. **NASA-9** — ДРУГАЯ,
несовместимая параметризация (девять коэффициентов, включая члены T⁻² и
T⁻¹; произвольное число диапазонов); NASA-7 и NASA-9 не смешиваются, и
каждая запись каталога фиксирует, какая форма использована.
Если термодинамика видов представляется полиномами NASA-7 (совместимо с
Cantera-подходом и упрощает валидацию против первоисточников), процесс
обязан включать: (1) получение и СОХРАНЕНИЕ исходных табличных данных
(возможность восстановить источник обязательна; полином не заменяет
оригинальные данные); (2) проверку температурного диапазона исходных
данных; (3) разделение диапазонов аппроксимации (как в NASA-7 — два
диапазона со стыком); (4) задокументированную процедуру аппроксимации
(метод, веса, контрольные точки); (5) величину ошибки аппроксимации
(max/средняя по контрольным точкам в каждом диапазоне); (6) неопределённость
исходных данных, переносимую из первоисточника; (7) ссылки на исходные
данные в provenance-записи вида.

## 3. Химическая термодинамика

### 3.1 Что строится

- Термодинамика реакции: ΔrH, ΔrS, ΔrG из данных видов; K(T) = exp(−ΔrG°/RT) —
  при СОГЛАСОВАННЫХ стандартных состояниях всех участников и в безразмерной
  форме (ревизия 4.0.1): термодинамическая константа равновесия безразмерна
  и строится из АКТИВНОСТЕЙ a_i (отнесённых к стандартному состоянию), а не
  из концентраций; термодинамическая активность отделена от обычной
  концентрации. Стандартное состояние (для газов — 1 бар идеального газа;
  для растворов — конкретная модель) фиксируется в каталоге для каждого
  вида; при валидации сравниваются log10 K с явным указанием стандартного
  состояния (VALIDATION_PLAN).
- Химические потенциалы: μ_i = μ_i° + RT ln a_i (газ: a → f/p°, фугитивность).
- Активности/фугитивности — иерархия моделей:
  1. идеальный газ / идеальный раствор (условия: низкие p, далёкие от
     критических, разбавленность — проверяются явно);
  2. кубические EOS (Peng–Robinson, SRK) для неидеального газа;
  3. модели коэффициентов активности растворов (Davies/Debye–Hückel для
     воды; Pitzer — позже; неводные растворители — отдельние модели с данными).
- Равновесия: газовая смесь, жидкая смесь, газ–жидкость (растворимость
  Генри с константами из источников), кислотно-основное (водная химия),
  окислительно-восстановительное (pe/pH), минералообразование.

### 3.2 Ограничения честности

- Идеальные модели применяются ТОЛЬКО при выполнении условий; иначе
  результат помечается приближением или не вычисляется.
- PHREEQC — ориентир АРХИТЕКТУРЫ (спецификация, кинетика минералов,
  ионный обмен), не универсальный решатель для всех сред: он построен
  вокруг водной химии; для неводных/сверхкритических сред — свои модели.

## 4. Химическая кинетика (независимый движок)

### 4.1 Модель

- Закон скорости r = k·Π c_i^ν применяется к ЭЛЕМЕНТАРНЫМ реакциям, где
  порядки по веществам следуют из механизма (молекулярности); для суммарных
  эмпирических реакций порядок определяется ИЗ ЭКСПЕРИМЕНТАЛЬНЫХ ДАННЫХ и
  не приравнивается автоматически к стехиометрическим коэффициентам — в
  каталоге каждой реакции явно указываются порядок и статус
  (elementary | overall_empirical);
- k(T) — Аррениус k = A·(T/300)^n·exp(−E_a/RT) (модифицированная форма
  JPL) или тройная troe-форма для давления-зависимых;
- единицы k зависят от порядка реакции, стандартного состояния и модели
  концентраций (например, c в моль/м³ для газовой фазы) — единицы
  фиксируются в каталоге для каждой реакции и согласуются со стандартным
  состоянием (ревизия 4.0.1);
- обратные реакции — либо прямо из данных, либо термодинамически
  согласованные через K(T) (только при наличии ΔG данных);
- механизмы: радикальные цепи, фотохимия (J-потоки из спектра × сечения),
  поверхностные реакции и граница раздела фаз — по мере данных.

### 4.2 Политика данных

- Источники: **JPL Chemical Kinetics and Photochemical Data for Use in
  Atmospheric Studies — Evaluation No. 20 (JPL Publication 25-1, 2025,
  DOI 10.48577/jpl.KFQ0TZ)** — приоритетный (проверено 30.10.2026 по
  официальной странице; параметры каждой реакции сверяются по таблицам,
  библиографии и диапазонам применимости самой публикации); KIDA — для
  низкотемпературной астрохимии с проверкой среды применимости
  (KIDA не является источником для водной химии).
- Каждая константа: A/n/E_a, T-диапазон, неопределённость (JPL указывает
  фактор), ссылка. Вне диапазона — экстраполяция запрещена без пометки.
- Данных нет → скорость `unknown` → реакция в механизме помечается
  «не рассчитано» (расширение текущего поведения `runKineticStep`).
- Произвольные коэффициенты вместо эксперимента — запрещено
  (`gameSpeedCoefficient` остаётся ТОЛЬКО в стехиометрическом
  игровом режиме, чётко отгороженном от кинетики).

## 5. Численные методы химии

### 5.1 Равновесие

- Задача: минимизация полной энергии Гиббса при ограничениях (элементы,
  заряд) — метод множителей Лагранжа (element potential / RAND-алгоритм),
  нелинейный решатель (Ньютон с линейным поиском).
- Контроль: сходимость по ΔG < tol, сохранение элементов/заряда до
  машинной точности, неотрицательность концентраций (лог-переменные).

### 5.2 Кинетика (ODE)

- Жёсткие системы: неявные методы (BDF/Radau) — интерфейс
  `SolverBackend`. Ревизия 4.0.1: диагональный якобиан НЕ объявляется
  достаточным для произвольных химических сетей (сеть связана через общие
  виды — якобиан в общем случае не диагонален). Интерфейс решателя
  допускает: аналитический якобиан; разреженный якобиан (структура
  реагентов/продуктов известна из механизма); численное приближение
  (конечные разности); другие подтверждённые стратегии нелинейного
  решения (Ньютон с линейным поиском / доверительной областью). Выбор
  стратегии — свойство механизма и фиксируется с ним. Устойчивость и
  точность проверяются на эталонной жёсткой задаче Robertson И на более
  реалистичных химических механизмах (сравнение с Radau-классом/внешним
  оракулом, сходимость при измельчении шага). На этом этапе решатель не
  реализуется; малые сети могут оставаться в TS, большие — через
  WASM/внешний движок (ADR-P7).
- Адаптивный шаг с контролем локальной ошибки; события (исчерпание
  реагента, достижение равновесия) — через detection + restart.
- Инварианты на каждом шаге: элементы, заряд, неотрицательность
  (клип с журналированием — не молча), энергетика (ΔH учёт при
  неизотермическом扩展).

### 5.3 Расщепление равновесия и кинетики

Равновесный расчёт и кинетическое продвижение — разные операции и
никогда не вызывают друг друга неявно. Ревизия 4.0.1: схема «быстрый
равновесный блок + медленный кинетический блок» НЕ универсальна для
произвольной сети. Режимы фиксируются явно:

1. **Независимый расчёт термодинамического равновесия** — отдельная
   операция анализа состояния (не «шаг эволюции»).
2. **Неравновесная кинетическая эволюция** — вся сеть интегрируется
   кинетически; равновесие не навязывается.
3. **Частичное равновесие** — часть реакций удерживается в равновесии
   ТОЛЬКО при обоснованном разделении временных масштабов (τ быстрых
   много меньше τ медленных) и с проверкой применимости приближения
   (диагностика: быстрое подмножество реально релаксирует внутри шага).
4. **Квазистационарные приближения (QSSA)** — только с проверкой условий
   (малость и быстрота релаксации QSS-видов).

Равновесие не навязывается медленным реакциям и системам, сохраняющим
кинетически неравновесное состояние (например, фотохимические продукты).
Расписание режимов — SIMULATION_ENGINE.

## 6. Многокомпонентные фазы и резервуары

- Фазы: газ, жидкая смесь, твёрдый раствор, минералы (стехиометрические
  конденсированные), растворённые газы, сверхкритический флюид (по
  критическим параметрам), аэрозоли; плазма — только при физическом
  обосновании (например, ионосфера) и данных.
- Несколько сосуществующих фаз: расчёт через общее равенство химических
  потенциалов (flash-расчёт) — целевой уровень после равновесного
  решателя; первый уровень — скрининг (сохраняется, честно помечен).
- Переходы: материальный баланс (уже есть в `transferSubstance`) +
  латентная теплота в тепловой контур (энергетическая связь — этап 4.8+).
- Один компонент может быть в нескольких резервуарах — текущий
  `SubstanceReservoirs` это уже поддерживает (контроль: суммы).

## 7. Геохимические циклы

- Каркас: направленные потоки между резервуарами (атмосфера, гидросфера,
  поверхность, кора, мантия, ядро, лёд, минералы, подповерхностные
  жидкости) в единых единицах **моль/м²/год** (или кг/м²/год с явным
  выбором), каждый поток = `ChemicalProcess` (реестр уже существует) +
  фактический rate, источник, неопределённость.
- Законы сохранения: элементный бюджет мира считается явным ledger'ом;
  сумма изменений за шаг = 0 (с точностью roundoff) — тест-инвариант.
- Процессы по мере данных: вулканическая дегазация, выветривание
  (параметрические законы с литературными константами), растворение/
  осаждение (через §3), поглощение океаном, окисление, атмосферная утечка,
  органический углерод (уровень «реестр без потока» до появления данных).
- Циклы: C, O, H, N, S, P, Si, металлы — реализуются как НАБОРЮЩИЕСЯ
  представления одного каркаса (не отдельные модули), начиная с C и O
  (кислородный баланс уже есть как частный случай — обобщается).

## 8. Критерии готовности

- **4.3 (каталог)**: ≥ 20 видов с термодинамикой (Cp-полином, ΔfH, S, G)
  и provenance; тесты полиномов против табличных значений при 298/1000/3000 K.
  Подэтап 4.3.1 (модель данных + валидация, +37 тестов) завершён;
  критерий 4.3 в целом остаётся открытым до фактического покрытия ≥20
  видов и завершения работы с NASA-7 (импорт и сверка NIST ↔ ATcT — 4.3.2).
- **4.4 (равновесие)**: решатель воспроизводит K известных равновесий
  (например, диссоциация NH₃/N₂-H₂ при высоких T по табличным данным,
  CO₂+H₂ ↔ CO+H₂O) с допуском < 1% — сравнение по log10 K при фиксированном
  стандартном состоянии (ревизия 4.0.1); сохранение элементов 1e-12.
- **4.5 (кинетика)**: сеть из JPL-данных; интегратор на тестовой жёсткой
  задаче (Robertson) с сохранением неотрицательности; трекинг неопределённости факторов JPL.
- **4.9 (циклы)**: закрытый цикл C на тестовом сценарии сохраняет углерод
  в пределах 1e-9 за 1000 шагов; каждый поток имеет источник или `unknown`.
