## 1. Модель происхождения данных (расширение PhysValue)

Каждое научное значение в каталогах обязано иметь:

```typescript
// Проект (Stage 4.3); текущее подмножество уже есть в PhysValue
interface ProvenancedValue<T> extends PhysValue<T> {
  origin: 'observed' | 'experimental' | 'reference_range'
        | 'derived_computed' | 'numerical_approximation'
        | 'theoretical_estimate' | 'game_assumption' | 'unknown';
  sourceVersion?: string;      // 'CODATA 2022', 'ATcT ver. 1.228', 'HITRAN2024'
  sourceId?: string;           // ID записи каталога/вещества
  checkedAt?: string;          // ISO-дата проверки
  uncertaintyKind?: 'none' | 'range' | 'sigma' | 'factor' | 'qualitative';
}
```

Правила: конфликт источников не решается случайным выбором — фиксируются
происхождение, метод, диапазон, неопределённость и причина выбора (ТЗ §19.7).
`unknown` не превращается в число неявно.

**Согласование схемы §1 с реализацией (Stage 4.3.1, 2026-10-31).**
Схема `ProvenancedValue` реализована для термодинамических значений как
`ThermoDataProvenance` (`src/modules/Core/thermodynamics.ts`):
типизированное происхождение значения `origin` (`ThermoValueOrigin`:
observed / experimental / reference_range / derived_computed /
numerical_approximation / theoretical_estimate / game_assumption /
unknown; runtime-реестр `THERMO_VALUE_ORIGINS`) поверх существующей
архитектуры — без дублирования уже имеющихся полей `ScientificValue` /
`DataProvenance` / `Uncertainty`: `sourceVersion` §1 → существующее
`datasetVersion`; идентификаторы — существующие `sourceId` / `datasetId` /
`recordId`; `checkedAt` §1 → существующее `retrievedAt`;
`uncertaintyKind` §1 → существующий `Uncertainty`. Каждое известное или
оценочное термодинамическое значение несёт СОБСТВЕННЫЙ provenance
(а не только общую ссылку на источник всего вещества): для known /
estimated без содержательного происхождения валидация возвращает ошибку;
отсутствие uncertainty НЕ трактуется как нулевая погрешность; для
`unknown` числовое значение не создаётся вовсе. Реальные источники
значений не добавлены: импорт и перекрёстная проверка ≥20 видов —
подэтап 4.3.2 (NIST Chemistry WebBook SRD 69 — основной источник;
ATcT TN 1.228 — приоритетный для сопоставления ΔfH°, лицензия остаётся
unverified: данные ATcT в дистрибутив не включаются до отдельной
проверки лицензии). DOI, CAS, WebBook ID, ATcT ID, даты проверки,
неопределённости и условия применимости не выдумываются.

Корректирующая ревизия 4.3.1 (validator hardening, 2026-10-31):
per-value provenance распространён на ОТДЕЛЬНЫЕ точки исходных

## 2. Каталог научных ресурсов

Формат записи соответствует ТЗ §19.7 (14 полей, компактно).

### 2.1 NIST CODATA — фундаментальные константы
- **Организация**: NIST (CODATA Task Group). **URL**: https://physics.nist.gov/cuu/Constants/ (карточка CODATA 2022: physics.nist.gov/cuu/pdf/wallet_2022.pdf).
- **Тип**: справочник констант. **Покрывает**: G, σ, элементарные константы, конверсии.
- **Среды**: универсальные. **Ограничения**: рекомендованные значения с неопределённостями; G — наименее точная фундаментальная константа.
- **Версия**: **CODATA 2022** — актуальный рекомендованный набор на дату
  ревизии 30.10.2026 (проверено: публикация доступна). Следующий
  четырёхлетний выпуск (CODATA 2026) ожидается отдельно — проверить после
  официальной публикации; значение константы НЕ подменяется только из-за
  появления нового календарного года. **Публикации**: Tiesinga et al.,
  2021/2024 (Rev. Mod. Phys./arXiv:2409.03787).
- **API**: таблицы/web. **Лицензия**: данные NIST общедоступны, цитирование обязательно. **Коммерческое**: допустимо с цитированием.
- **Интеграция**: Units — заменить ярлык «CODATA 2018» на «CODATA 2022» (значения используемых констант не изменились; проверено по карточке 2022).
- **Тесты**: единичные значения констант; согласованность производных (σ против h,c,k — на уровне 4.10).

### 2.2 NIST Chemistry WebBook (SRD 69)
- **Организация**: NIST. **URL**: https://webbook.nist.gov/chemistry/.
- **Тип**: база данных. **Покрывает**: молярные массы, термохимия газовой фазы (ΔfH°, S°, Cp), ионная энергетика, фазовые переходы, Antoine-корреляции, спектры (частично).
- **Среды**: индивидуальные вещества; диапазоны для корреляций указаны по записям.
- **Версия**: живой SRD 69; последнее обновление данных — **2025** (ревизия
  4.0.1, проверено на официальной странице). При импорте значений
  фиксируются дата проверки и идентификатор конкретной записи (WebBook ID).
  **Публикации**: по каждой записи.
- **API**: HTTP-запросы по ID. **Лицензия**: общедоступные данные NIST, цитирование.
- **Интеграция**: главный источник термодинамики веществ (этап 4.3) + расширение Antoine-наборов за пределы CH₄/C₂H₆ (уже используется).
- **Тесты**: значения ΔfH°/S°/Cp при 298 K против таблиц; Antoine против точек кипения.

### 2.3 Active Thermochemical Tables (ATcT)
- **Организация**: Argonne National Laboratory. **URL**: https://atct.anl.gov/.
- **Тип**: база термохимических данных, построенная на network-анализе (ТН-сеть), с квантованными неопределённостями.
- **Версия (ревизия 4.0.2)**: **TN 1.228** — последняя выпущенная версия,
  проверено 30.10.2026 по официальной странице atct.anl.gov (перечень
  выпусков: Thermochemical Data → version 1.228; цитирование публикаций
  ATcT — «version 1.228 of the Thermochemical Network, Argonne National
  Laboratory, 2026, available at ATcT.anl.gov»). Ревизия 4.0.1 ошибочно
  указала 1.122 как последнюю — исправлено в 4.0.2. **TN 1.222, TN 1.220
  и TN 1.122** — более ранние выпуски: упоминаются только как исторические
  ссылки для воспроизводимости прежних расчётов и НЕ называются
  актуальными. TN 1.228 НЕ обязательно содержит данные для каждого
  необходимого химического вида — покрытие проверяется отдельно по каждой
  записи (отсутствующее значение → unknown, не подстановка из другого
  источника без пометки).
- **Per-record provenance (ревизия 4.0.2)**: каждое импортируемое значение
  обязано фиксировать: версию набора данных (TN 1.228; конкретная
  историческая — только для воспроизводимости прежних расчётов),
  идентификатор вещества/записи (ATcT ID / CAS RN), дату получения,
  происхождение (страница версии).
- **Лицензия (ревизия 4.0.2)**: ATcT — DOE Office of Science Public
  Reusable (PuRe) Data Resource (статус получен в марте 2023; официальная
  страница и пресс-релизы DOE/ANL). PuRe-статус НЕ определяет
  автоматически конкретные права на распространение данных в нашем
  продукте; точные условия использования по данным не удалось подтвердить
  проверяемым источником — до проверки действует ограничение
  **unverified**: не включать данные ATcT в дистрибутив без отдельной
  лицензионной проверки; не называть «академической лицензией» без
  источника.
- **Интеграция**: приоритетный источник ΔfH° (более современная согласованная оценка, чем JANAF); сравнение с JANAF фиксировать при расхождениях.
- **Тесты**: перекрёстная проверка ΔfH° WebBook ↔ ATcT; расхождения > 2σ — фиксировать в каталоге с причиной выбора.

### 2.4 NIST-JANAF Thermochemical Tables
- **Организация**: NIST. **URL**: https://janaf.nist.gov/. **Тип**: исторические таблицы.
- **Ограничение**:.archive — НЕ считать более актуальным, чем ATcT (требование ТЗ §19.1).
- **Интеграция**: вторичная проверка; формат NASA-полиномов исторически связан.
- **Тесты**: согласованность Cp(T) с полиномами каталога.

### 2.5 IUPAC Gold Book
- **Организация**: IUPAC. **URL**: https://goldbook.iupac.org/. **Тип**: терминологический справочник.
- **Покрывает**: определения (хим. потенциал, активность, фугитивность, K, стандартные состояния...).
- **Интеграция**: глоссарий терминов ядра + проверки документации (терминология кода/доков должна совпадать с IUPAC).
- **Тесты**: не численные; стандарт согласования терминов в ревью.

### 2.6 NASA JPL Chemical Kinetics and Photochemical Data Evaluation
- **Организация**: NASA JPL. **URL**: https://science.jpl.nasa.gov/projects/data-evaluation/ (зеркало загрузки: jpldataeval.jpl.nasa.gov).
- **Тип**: периодическая экспертная оценка данных. **Покрывает**: газофазные и гетерогенные атмосферные реакции, фотолиз, константы Аррениуса, T-диапазоны, неопределённости.
- **Версия (проверено, ревизия 4.0.1)**: **Evaluation No. 20**, **JPL
  Publication 25-1**, год публикации **2025**, DOI **10.48577/jpl.KFQ0TZ**
  (официальная страница проекта). Конкретные параметры КАЖДОЙ реакции
  проверяются по таблицам, библиографии и диапазонам применимости самой
  публикации — номер выпуска не отменяет per-record проверку.
- **Лицензия**: government work; условия использования проверить.
- **Интеграция**: этап 4.5 — основной источник кинетики атмосферной химии; формат данных (A, n, E/R) напрямую ложится на §4.1 CHEMISTRY_ARCHITECTURE.

- **Тип**: оценённая база ядерных свойств: массовые числа, периоды полураспада, изомерные состояния (звёздочка), режимы распада; разделение экспериментальных и оценённых (экстраполированных) значений.
- **Версия**: NUBASE2020 — Kondev et al., Chinese Physics C 45 (2021) 030001, DOI 10.1088/1674-1137/abddae (проверено 2026-11-01: более нового официального релиза NUBASE/AME на AMDC не опубликовано; версия не меняется по дате).
- **Интеграция** (4.3.3): Data/elementIsotopeCandidates.ts — 34 элемента без стандартного атомного веса: 44 записи-кандидата / 3 изомерных состояния (Hs-277m, Mt-276m, Lv-293m) / 43 уникальные пары (Z,A) — у Lv-293 основное и изомерное состояния одного массового числа, поэтому число записей НЕ называется числом уникальных нуклидов; Md-258 — основное состояние (строка i=0, Isom.Unc=* — неопределённость порядка основного/изомерного состояний, не признак изомера; 258Mdm 57.0(9) мин — отдельная строка, не кандидат); включаются только экспериментальные записи (оценённые значения с решёткой # не выдаются за экспериментальные); все 44 записи сверены построчно с официальным ASCII-файлом NUBASE2020 (Z, A, индекс состояния i, Isom.Unc, T1/2, единица, неопределённость, режим распада, отсутствие # в поле T1/2 — таблица соответствия в elementDataAttribution.md §7); provenance nubase, recordId вида nubase2020:Z=43 Tc A=97.
- **Ограничения**: полнота отбора — 14 complete / 20 incomplete (Z=99–118: известные нуклиды не доказывают абсолютный максимум; complete — воспроизводимая полнота в пределах NUBASE2020 по ранжированию всех экспериментально наблюдавшихся строк, elementDataAttribution.md §7.1, а не абсолютный максимум); при перекрывающихся опубликованных 1σ-интервалах победитель не выбирается: перекрытие интервалов само по себе не доказывает статистической эквивалентности значений (статистический анализ не выполнялся), по принятому консервативному правилу отбора сохранены все пересекающиеся кандидаты, единственный не назначается; построчная сверка с ENSDF не выполнялась (сверка с официальным ASCII-файлом NUBASE2020 выполнена, см. §7 атрибуции) — расхождения не разрешаются молчаливым выбором.

### 2.27 NIST Atomic Weights and Isotopic Compositions — НЕ используется
- **URL**: https://physics.nist.gov/cgi-bin/Compositions/stand_alone.pl. **Статус**: не подключён в 4.3.3: база содержит устаревшую комбинацию источников (Atomic Weights 2013, isotopic compositions 2009, AME2012; обновлялась в 2015), и разрешение на распространение её числовых записей не подтверждено.
- **Следствие**: числовые свойства, для которых единственным удобным источником является эта база (электронные конфигурации, энергии ионизации, сродство, электроотрицательность, радиусы, температуры фазовых переходов, плотности), остаются unknown до подтверждения лицензии.
