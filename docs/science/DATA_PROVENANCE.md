# DATA_PROVENANCE — Источники данных, достоверность, неопределённость

> Stage 4.0. Проверено 2026-10-30. Помечено, что именно проверено в этой
> сессии, а что требует ручной проверки перед включением.

## 1. Модель происхождения данных (расширение PhysValue)

Каждое научное значение в каталогах обязано иметь:

```typescript
// Проект (Stage 4.3); текущее подмножество уже есть в PhysValue
interface ProvenancedValue<T> extends PhysValue<T> {
  origin: 'observed' | 'experimental' | 'reference_range'
        | 'derived_computed' | 'numerical_approximation'
        | 'theoretical_estimate' | 'game_assumption' | 'unknown';
  sourceVersion?: string;      // 'CODATA 2022', 'ATcT ver. 1.220', 'HITRAN2020'
  sourceId?: string;           // ID записи каталога/вещества
  checkedAt?: string;          // ISO-дата проверки
  uncertaintyKind?: 'none' | 'range' | 'sigma' | 'factor' | 'qualitative';
}
```

Правила: конфликт источников не решается случайным выбором — фиксируются
происхождение, метод, диапазон, неопределённость и причина выбора (ТЗ §19.7).
`unknown` не превращается в число неявно.

## 2. Каталог научных ресурсов

Формат записи соответствует ТЗ §19.7 (14 полей, компактно).

### 2.1 NIST CODATA — фундаментальные константы
- **Организация**: NIST (CODATA Task Group). **URL**: https://physics.nist.gov/cuu/Constants/ (карточка CODATA 2022: physics.nist.gov/cuu/pdf/wallet_2022.pdf).
- **Тип**: справочник констант. **Покрывает**: G, σ, элементарные константы, конверсии.
- **Среды**: универсальные. **Ограничения**: рекомендованные значения с неопределённостями; G — наименее точная фундаментальная константа.
- **Версия**: **CODATA 2022** (проверено: публикация 2022 доступна). **Публикации**: Tiesinga et al., 2021/2024 (Rev. Mod. Phys./arXiv:2409.03787).
- **API**: таблицы/web. **Лицензия**: данные NIST общедоступны, цитирование обязательно. **Коммерческое**: допустимо с цитированием.
- **Интеграция**: Units — заменить ярлык «CODATA 2018» на «CODATA 2022» (значения используемых констант не изменились; проверено по карточке 2022).
- **Тесты**: единичные значения констант; согласованность производных (σ против h,c,k — на уровне 4.10).

### 2.2 NIST Chemistry WebBook (SRD 69)
- **Организация**: NIST. **URL**: https://webbook.nist.gov/chemistry/.
- **Тип**: база данных. **Покрывает**: молярные массы, термохимия газовой фазы (ΔfH°, S°, Cp), ионная энергетика, фазовые переходы, Antoine-корреляции, спектры (частично).
- **Среды**: индивидуальные вещества; диапазоны для корреляций указаны по записям.
- **Версия**: живой SRD 69. **Публикации**: по каждой записи.
- **API**: HTTP-запросы по ID. **Лицензия**: общедоступные данные NIST, цитирование.
- **Интеграция**: главный источник термодинамики веществ (этап 4.3) + расширение Antoine-наборов за пределы CH₄/C₂H₆ (уже используется).
- **Тесты**: значения ΔfH°/S°/Cp при 298 K против таблиц; Antoine против точек кипения.

### 2.3 Active Thermochemical Tables (ATcT)
- **Организация**: Argonne National Laboratory. **URL**: https://atct.anl.gov/.
- **Тип**: база термохимических данных, построенная на network-анализе (ТН-сеть), с квантованными неопределённостями.
- **Версия**: **ver. 1.220** (проверено: страница версии существует; также известна ver. 1.124).
- **Лицензия**: академическое использование; условия перепроверить перед включением в дистрибутив.
- **Интеграция**: приоритетный источник ΔfH° (более современная согласованная оценка, чем JANAF); сравнение с JANAF фиксировать при расхождениях.
- **Тесты**: перекрёстная проверка ΔfH° WebBook ↔ ATcT; расхождения > 2σ — фиксировать в каталоге с причиной выбора.

### 2.4 NIST-JANAF Thermochemical Tables
- **Организация**: NIST. **URL**: https://janaf.nist.gov/. **Тип**: исторические таблицы.
- **Ограничение**:.archive — НЕ считать более актуальным, чем ATcT (требование ТЗ §19.1).
- **Интеграция**: вторичная проверка; формат NASA-полиномов исторически связан.
- **Тесты**: согласованность Cp(T) с полиномами каталога.

### 2.5 IUPAC Gold Book
- **Организация**: IUPAC. **URL**: https://goldbook.iupac.org/. **Тип**: терминологический справочник.
- **Покрывает**: определения (хим. потенциал, активность, фугитивность, K, стандартные состояния...).
- **Интеграция**: глоссарий терминов ядра + проверки документации (терминология кода/доков должна совпадать с IUPAC).
- **Тесты**: не численные; стандарт согласования терминов в ревью.

### 2.6 NASA JPL Chemical Kinetics and Photochemical Data Evaluation
- **Организация**: NASA JPL. **URL**: https://science.jpl.nasa.gov/projects/data-evaluation/ (зеркало загрузки: jpldataeval.jpl.nasa.gov).
- **Тип**: периодическая экспертная оценка данных. **Покрывает**: газофазные и гетерогенные атмосферные реакции, фотолиз, константы Аррениуса, T-диапазоны, неопределённости.
- **Проверено в сессии**: существование официального проекта и страницы загрузки; страница загрузки блокирует автоматический доступ — **точный выпуск (заявленный Evaluation No. 20, JPL Pub. 25-1) проверить вручную перед использованием данных**.
- **Лицензия**: government work; условия использования проверить.
- **Интеграция**: этап 4.5 — основной источник кинетики атмосферной химии; формат данных (A, n, E/R) напрямую ложится на §4.1 CHEMISTRY_ARCHITECTURE.
- **Тесты**: unit-тесты воспроизведения k(T) по табличным константам на краях заявленных диапазонов; вне диапазона — пометка.

### 2.7 KIDA — Kinetic Database for Astrochemistry
- **Организация: astrochem-tools community**. **URL**: https://kida.astrochem-tools.org/ (networks: /networks).
- **Тип**: база кинетики + сети реакций. **Покрывает**: межзвёздная/планетарная газовая химия, низкотемпературные процессы.
- **Ограничения**: НЕ источник для водной химии/геохимии; каждой записи — своя среда/T-диапазон (проверять per record). Публикация-основа: Wakelam et al. 2012, ApJS 199:21 (проверено: запись существует).
- **Лицензия**: открытый доступ к данным; сети имеют своих кураторов.
- **Интеграция**: этап 4.5+ — холодные атмосферы (Титан-класс, экзосферы).
- **Тесты**: сравнение k(T) с первоисточниками записей.

### 2.8 NASA/JPL SSD + Horizons API
- **Организация**: JPL SSD. **URL**: https://ssd.jpl.nasa.gov/, API: https://ssd-api.jpl.nasa.gov/doc/horizons.html.
- **Тип**: эфемеридная система + API. **Версия API**: **1.3 (2025 June)** (проверено по документации).
- **Покрывает**: эфемериды, орбитальные элементы, физические параметры тел, системы отсчёта, шкалы времени.
- **Важно**: эфемериды ≠ N-body интегратор (ТЗ §19.3): Horizons — источник эталонных ЗНАЧЕНИЙ.
- **Лицензия**: открытое использование, US government work.
- **Интеграция**: эталонные тесты валидации орбит (уровень 2–3 VALIDATION_PLAN): периоды, расстояния, элементы.
- **Тесты**: периоды Луны/Ио/Титана из Horizons против нашего Кеплера при заданных a, M.

### 2.9 NAIF SPICE Toolkit
- **Организация**: JPL NAIF. **URL**: https://naif.jpl.nasa.gov/naif/toolkit.html.
- **Тип**: программный комплекс наблюдательной геометрии + kernels.
- **Покрывает**: системы отсчёта, времена (ET/UTC/UTC-лептосекунды), геометрия, ориентация тел.
- **Ограничение**: C/Fortran/Python — не TS; в браузере напрямую не используется.
- **Интеграция**: (а) эталон времени/систем отсчёта для спецификации sim/; (б) тестовые значения из kernels вручную.
- **Проверка**: страница не открывалась в этой сессии автоматически — подтвердить содержимое при интеграции.

### 2.10 NASA Exoplanet Archive
- **Организация**: IPAC/Caltech. **URL**: https://exoplanetarchive.ipac.caltech.edu/.
- **Тип**: база наблюдательных данных. **Покрывает**: параметры экзопланет и звёзд-хозяев, неопределённости, ссылки на публикации; различие измерено/выведено — в полях.
- **Лицензия**: открытое научное использование с цитированием.
- **Интеграция**: Stage 4.6 — реалистические диапазоны для сэмплирования (диапазоны классов с источниками); валидационные пары (транзитные системы).
- **Тесты**: сэмплы внутри заявленных диапазонов; сравнение M-R распределений.

### 2.11 NASA PDS / PDS Atmospheres Node
- **Организация**: NASA PDS. **URL**: https://pds.nasa.gov/ (стандарт PDS4; DPH v1.12.0 — проверено: документ существует).
- **Тип**: архив миссий. **Покрывает**: измерения атмосфер, поверхностей, спектры миссий.
- **Интеграция**: эталонные профили планет для VALIDATION_PLAN уровня 3 (Венера/Марс/Титан из миссий), с указанием instrument/PDS ID в provenance.
- **Тесты**: сценарии «модель против измерений миссий» с явными допусками.

### 2.12 HITRAN (HITRAN2020 / HITRANonline)
- **Организация**: HITRAN collaboration (Harvard-Smithsonian CfA и др.). **URL**: https://hitran.org/.
- **Тип**: база спектральных линий. **Актуальное издание**: **HITRAN2020** (Gordon et al. 2022, JQSRT; проверено: издание существует как последнее крупное; онлайн-версия обновляется).
- **Покрывает**: параметры линий, изотопологи, сечения, неопределённости по записям.
- **Среды**: земные и умеренные атмосферы; для горячих — ExoMol.
- **Лицензия**: бесплатноe использование с регистрацией/цитированием; условия проверить.
- **Интеграция**: этап 4.8 — предрассчёт k-таблиц (офлайн, версионные артефакты с provenance).
- **Тесты**: полосы CO₂/H₂O/CH₄ в k-таблицах против эталонных сечений.

### 2.13 ExoMol
- **URL**: https://www.exomol.com/ (проверено: база и страницы databases существуют).
- **Тип**: линейные списки молекул для горячих атмосфер. **Покрывает**: T-расширенные списки (до тыс. K).
- **Интеграция**: те же k-таблицы для горячих миров; версии баз фиксировать.

### 2.14 NASA Planetary Spectrum Generator (PSG)
- **Организация**: NASA/GSFC. **URL**: https://psg.gsfc.nasa.gov/ (документация /help.php). **Тип**: онлайн радиационный перенос (Villanueva et al. 2018, arXiv:1803.02008 — проверено).
- **Покрывает**: атмосферные модели, перенос, рассеяние, поверхности, экзосферы, геометрия.
- **Интеграция**: (а) архитектурный ориентир для atmos/; (б) оракул для валидации наших RCM/spectral-модулей (сценарии сравнения с официальными примерами); (в) НЕ встраивается в рантайм.
- **Тесты**: сравнение спектров/профилей на эталонных конфигурациях.

### 2.15 ROCKE-3D 2.0 и LMD Planetary GCM
- **ROCKE-3D 2.0**: NASA GISS (проверено: Tsigaridis et al. 2025, GMD 18, 5825 — публикация существует). 3D GCM для каменистых планет.
- **LMD GCM Planets**: LMD/IPSL (страницы не открывались автоматически в этой сессии — проверить документацию при интеграции).
- **Интеграция**: только как (а) ориентир сопряжения физических процессов (радиация+динамика+поверхность+орбита), (б) внешний эталон. Собственная 3D GCM НЕ планируется (ТЗ §19.5).

### 2.16 REBOUND
- **Автор**: Hanno Rein et al. **URL**: https://github.com/hannorein/rebound. **Лицензия**: **GPLv3** (проверено: файл LICENSE).
- **Тип**: N-body интегратор (C/Python); WHFast, IAS15 и др.
- **Интеграция**: (а) эталонный оракул для тестов наших интеграторов (орбитальные задачи с известными аналитическими/численными решениями); (б) возможная WASM-сборка — только после лицензионного анализа GPLv3 в браузерном продукте (консультация с владельцем проекта).
- **Тесты**: сходимость leapfrog против REBOUND на тестовой задаче (офлайн).

### 2.17 Cantera
- **Организация**: Cantera project. **URL**: https://cantera.org/. **Лицензия**: файл License.txt в репозитории (BSD-подобная; сверить текст при подключении).
- **Тип**: термодинамика/кинетика/транспорт, реакторные сети.
- **Интеграция**: ГЛАВНЫЙ архитектурный ориентир chem/ (фазы-объекты, механизмы, решатели); формат NASA-полиномов совместим; оракул для валидации равновесия/кинетики (офлайн).
- **Тесты**: сравнение K_eq и кинетических траекторий на общих механизмах.

### 2.18 USGS PHREEQC
- **Организация**: USGS. **URL**: https://www.usgs.gov/software/phreeqc-version-3. **Версия**: серия 3.x (проверено: R-интерфейсы 3.7–3.8; ядро 3.x).
- **Лицензия**: ПО США (public domain) — база данных тоже; проверить формулировку.
- **Тип**: водная геохимия (спецификация, растворение/осаждение, ионный обмен, кинетика).
- **Интеграция**: ориентир для водной химии и океан↔порода (CHEMISTRY §3.3, §7); данные (llnl.dat и др.) — с проверкой лицензий каждой базы.
- **Ограничение**: не универсален для неводных/сверхкритических сред.

### 2.19 CoolProp
- **URL**: https://coolprop.org/. **Лицензия**: **MIT** (проверено: страница LICENSE на GitHub).
- **Тип**: термодинамические/транспортные свойства флюидов и смесей; EOS (SRK, PR, PC-SAFT и др.).
- **Интеграция**: (а) источник формул/структур для нашего EOS-слоя (реализация собственная в TS — MIT допускает с сохранением копирайта; сверить файл), (б) оракул для валидации. REFPROP-бэкенд CoolProp требует отдельной лицензии REFPROP — не использовать.
- **Тесты**: наши PR/SRK против CoolProp на эталонных точках (офлайн).

### 2.20 NIST REFPROP (SRD 23)
- **URL**: https://www.nist.gov/srd/refprop. **Версия**: v10 (проверено: страница; платное обновление в магазине NIST).
- **Лицензия**: **платная**, royalty-условия — НЕ подключать без отдельного решения владельца проекта (ТЗ §19.6). Данные чистых веществ можно сверять с WebBook (бесплатно).

## 3. Сравнительная матрица: своя реализация / внешняя библиотека / внешний сервис

| Возможность | Своя TS-реализация | Внешняя библиотека (WASM/офлайн) | Внешний сервис |
|---|---|---|---|
| Кеплер, T_eq, столб, гидростатика | ✅ сейчас | не нужна | не нужна |
| N-body | leapfrog малых N (4.6) | REBOUND (GPLv3 — анализ) | — |
| Термодинамика видов | ✅ каталог + полиномы (4.3) | Cantera как оракул | — |
| Равновесие | ✅ свой решатель (4.4) | Cantera (оракул) | — |
| Кинетика | ✅ BDF малых сетей (4.5) | Cantera/WASM при росте | — |
| EOS (PR/SRK) | ✅ свой слой (4.4+) | CoolProp (MIT) как оракул | — |
| Водная геохимия | каркас (4.9) | PHREEQC как ориентир/оракул | — |
| Спектры/k-таблицы | офлайн-предрассчёт (4.8) | HITRAN/ExoMol данные | PSG как оракул |
| Климат 3D | НЕ строим | — | внешний GCM-интерфейс (далёкая цель) |

Принцип: **данные покупаем/берём из открытых баз с цитированием; модели
реализуем сами на уровне TS, где реалистично; сложные решатели не
переписываем, а подключаем через интерфейс или используем как оракулов
для тестов.**
